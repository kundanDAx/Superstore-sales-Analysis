# Superstore-sales-Analysis
Superstore Sales analysis using Python,Excel,and Power BI


## Project Overview

This project analyzes Superstore sales data using Python, Excel, and Power BI.

The goal is to understand sales performance across categories, sub-categories, regions, customer segments, months, and years.

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Excel
- Power BI

## Analysis Performed

- Category-wise sales analysis
- Sub-category-wise sales analysis
- Top 10 products by sales
- Region-wise sales analysis
- Customer segment-wise sales analysis
- Month-wise sales analysis
- Year-wise sales analysis

## Dashboard KPIs

- Total Sales
- Total Orders
- Total Customers
- Total Products

## Key Insights

- Technology is the highest-selling category.
- Phones is the highest-selling sub-category.
- Sales performance was compared across regions and customer segments.
- Monthly and yearly sales trends were analyzed.

## Files

- `Superstore_Sales_Analysis.ipynb` — Python/Jupyter analysis
- `superstore_sales_analysis.xlsx` — Excel data
- `Superstore_Sales_Analysis.pbix` — Power BI dashboard

## Conclusion

This project demonstrates practical skills in data cleaning, exploratory data analysis, visualization, and dashboard development using Python, Excel, and Power BI.
